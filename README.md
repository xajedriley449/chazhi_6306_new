# 6306每日能量云图绘图脚本

将 plot_6306_clouds.py 放到项目根目录，与 output_6306_daily_xy 目录同级。
原预处理脚本和NPZ文件均不需要修改。

## 安装与运行

```bash
pip install numpy pandas matplotlib
python plot_6306_clouds.py --root output_6306_daily_xy --dates 2020-03-13 2020-05-15 2023-12-19
```

输出在 output_6306_daily_xy/paper_figures。每一天一张低/高双栏图，保存300 dpi PNG与PDF；选择2至6天时另存comparison对比图。

全部日期：

```bash
python plot_6306_clouds.py --root output_6306_daily_xy --all --output figures_all
```

可选参数：--vmax-low 10000 --vmax-high 250000 --linthresh 1 --dpi 300。
重复运行请使用新--output目录，防止混入旧图。
程序自动读取根目录下唯一的dataset_config*.json，以及events_selected.csv。
事件表缺失时仍可绘图，但没有位置叠加和事件表能量核验。可用--config/--events明确指定文件路径。

## 色标规则

1. 读取energy_J，即真实J按归一化高斯核分配到网格后的数值。不修改energy_log10、训练输入或标签。
2. 默认低能上限10000 J/格，高能上限250000 J/格，均为绘图显示参数，不是分类阈值或危险阈值。
3. 所有日期的同一通道使用同一色标。低/高通道色标不同，不能仅按颜色跨通道比较强度，须读颜色条数值。
4. SymLogNorm：1 J/格以内线性，以上按对数映射颜色。零值单独显示为白色。
5. 超出上限只截显示颜色，不截数据；标题、颜色条和plot_audit.csv明确记录。
6. 图示保持实际XY长宽比和原始64x64网格，未增大50m带宽，也未对数值做空间再插值。空间显示比旧正方形像素图更符合米制坐标比例。
7. 每个事件能量分配到多个格点，所以单格能量低于事件能量是正常现象。单事件阈值100000 J不应用到平滑后的每格数值。
8. 白色只表示目录网格能量为零，不证明全天监测正常，也不代表区域安全。

## 论文表述建议

应称为“按能级划分的微震空间能量分布（高斯平滑）”，不能把此图称为模型预测结果、应力场或真实破坏范围。
图注需说明：日窗口；原始单事件能量10^5 J分级；64×64网格；50 m带宽、3σ截断；每事件核在网格内归一化；颜色条为J/格，采用非线性显示；圆圈为目录事件位置；同通道跨日期固定色标。
这些日期是用户提供的示例，用于检查预处理与显示，不构成模型效果评估。
